Voicely Translate 是一个 Discord 机器人，可自动转录并翻译语音频道中的对话。

当机器人在语音频道中处于活动状态时，它会分别监听每位说话者，转录其说话内容，并将原始转录和翻译发布到语音频道的侧边聊天中。

可以同时启用多种翻译语言，并且在机器人已经进行翻译时也可以添加或移除语言。

## 功能

* 自动转录 Discord 语音频道中的语音。
* 同时将对话翻译成多种语言。
* 将转录和翻译直接发布到语音频道的侧边聊天中。
* 支持多人说话，包括彼此语音重叠的情况。
* 无需重新启动会话即可添加或移除翻译语言。
* 使用 BCP 47 语言标签，因此可以请求固定内置列表之外的语言。
* 在可配置的超时时间后自动离开空的语音频道。
* 可选择与 [**Voicely Text**](https://discord.com/application-directory/1290741552158609419) 配合使用，以朗读翻译后的消息。

## 将 Voicely Translate 添加到你的服务器

使用[此邀请链接](https://discord.com/oauth2/authorize?client_id=1535789654974930964)将 Voicely Translate 添加到你的 Discord 服务器。

安装后，其命令将作为 Discord 斜杠命令提供。

要开始翻译，请加入普通的 Discord 语音频道并使用：

`/join`

你必须已经位于希望 Voicely Translate 加入的语音频道中。

## 开始翻译会话

使用：

`/join`

`languages` 选项是可选的。如果指定了语言，翻译会话将使用这些语言：

`/join languages:<语言标签>`

使用逗号分隔多种语言。

例如：

`/join languages:en,ja`

这将启动一个启用英语和日语的翻译会话。

你可以根据需要启用任意数量的语言：

`/join languages:en,ja,es,fr,de,ko`

如果使用 `/join` 时没有指定任何语言，Voicely Translate 将使用服务器的默认翻译语言。

如果服务器尚未配置任何默认语言，机器人会要求你指定语言，或让服务器管理员配置默认语言。

连接后，Voicely Translate 会将转录和翻译发布到**该语音频道的侧边聊天中**。

## 默认翻译语言

服务器管理员可以设置当用户运行 `/join` 且未指定 `languages` 选项时 Voicely Translate 使用的语言。

使用：

`/defaultlanguages languages:<语言标签>`

例如：

`/defaultlanguages languages:en,ja`

将英语和日语设置为服务器的默认翻译语言。

使用逗号分隔多种语言：

`/defaultlanguages languages:en,ja,es,fr`

这些默认设置会保存到该 Discord 服务器，并一直有效，直到服务器管理员进行更改。

在 `/join` 中直接指定语言会覆盖该翻译会话的服务器默认语言，但不会更改已保存的默认设置。

此命令需要**管理员**权限。

## 语言标签

Voicely Translate 使用语言标签而不是语言名称。

例如：

* `en` — 英语
* `ja` — 日语
* `es` — 西班牙语
* `fr` — 法语
* `de` — 德语
* `ko` — 韩语
* `zh` — 中文
* `haw` — 夏威夷语

也可以使用区域或文字系统特定的 BCP 47 标签，例如 `pt-BR` 或 `zh-TW`。

使用：

`/languages`

以查看常用语言标签的参考列表。

机器人**并不限于 `/languages` 中显示的语言**。你也可以尝试其他有效的 BCP 47 语言标签。

## 在翻译过程中更改语言

仅仅为了更改语言，无需让机器人退出后重新加入。

### 添加语言

使用：

`/add languages:<语言标签>`

例如：

`/add languages:fr,ko`

将法语和韩语添加到当前翻译会话。

### 移除语言

使用：

`/remove languages:<语言标签>`

例如：

`/remove languages:en,fr`

从当前翻译会话中移除英语和法语。

移除语言只会影响之后的翻译。机器人仍可继续翻译为任何保持启用的语言。

### 查看活动语言

使用：

`/active`

以查看当前启用了哪些翻译语言。

## 停止翻译

使用：

`/leave`

以停止当前翻译会话并让 Voicely Translate 离开语音频道。

当语音频道中无人时，机器人也可以自动离开。

## 空语音频道超时

服务器管理员可以控制 Voicely Translate 在空语音频道中等待多久后自动离开。

使用：

`/timeout seconds:<秒数>`

例如：

`/timeout seconds:60`

会让机器人在语音频道变空后等待 60 秒。

默认超时时间为 **30 秒**。

此命令需要**管理员（Administrator）**权限。

## Voicely Credits

Voicely Translate 使用积分系统来支付处理语音对话所需的转录和翻译服务费用。

**100 Voicely Credits = $1.00 USD.**

新服务器目前可获得 **50 个免费试用积分**。这大约足够处理 **1,000 条 5 秒的语音消息**，但实际使用量可能有所不同。

语音被转录和翻译时会消耗积分。使用量会根据说话量以及请求的翻译数量而变化。

启用更多翻译语言可能会增加使用量，因为每份转录都需要翻译成所请求的语言。

### 查看余额

使用：

`/balance`

以查看：

* 可用积分
* 剩余免费试用积分
* 已购买积分

### 查看使用量

使用：

`/usage`

以查看服务器累计使用量，包括：

* API 总使用量
* 转录使用量
* 翻译使用量
* 已购买积分总数

积分余额和使用量属于 **Discord 服务器**，而不是某个单独的 Discord 用户。

## 添加更多积分

服务器管理员可以使用：

`/topup`

Voicely Translate 会提供该服务器专属的充值代码，以及通过 Ko-fi 购买额外积分的说明。

付款时，请在 Ko-fi 付款消息中包含提供的充值代码。

每 **$1.00 USD 可增加 100 Voicely Credits**。

付款后，使用：

`/balance`

或者直接使用 `/join` 启动机器人。

Voicely Translate 会自动检查新购买的积分。

`/topup` 命令需要**管理员（Administrator）**权限。

## 翻译的工作方式

当有人在语音频道中说话时，Voicely Translate 会独立处理该人的语音。

基本流程如下：

1. Voicely Translate 接收说话者的语音音频。
2. 音频会以实际所说的语言进行转录。
3. 转录内容会被翻译成当前启用的语言。
4. 原始转录和翻译会发布到语音频道的侧边聊天中。

由于每位说话者都是独立处理的，因此机器人旨在处理多人同时或几乎同时说话的对话。

系统会使用短暂的停顿来判断一句话何时结束，然后再将其发送进行转录。

非语言声音和单独出现的犹豫音可能会被忽略，而不会作为消息发布。

## 示例

假设语音频道中有三个人，并启用了英语、日语和西班牙语。

有人说：

> Are we ready to go?

Voicely Translate 可能会发布原始转录以及如下翻译：

**原文 — 英语**  
Are we ready to go?

**日语**  
もう行く準備はできた？

**西班牙语**  
¿Estamos listos para irnos?

确切的格式和翻译可能有所不同。

## 使用 Voicely Text

Voicely Translate 的设计目标是以文本形式显示翻译。

如果你还希望翻译后的消息能**在语音频道中朗读出来**，可以将 Voicely Translate 与 [**Voicely Text**](https://discord.com/application-directory/1290741552158609419) 一起使用。

当 Voicely Translate 加入未安装 Voicely Text 的服务器时，它可能会提供添加该机器人的链接。

## 获得更好结果的提示

为了获得最佳的转录和翻译质量：

* 清晰地以正常音量说话。
* 避免极其响亮的背景音乐或噪音。
* 使用最适合对话的语言标签。
* 请记住，自动转录和翻译可能会出错，尤其是在姓名、俚语、非常短的发言、严重背景噪音或含糊语音的情况下。
* 当地区差异很重要时，请使用区域语言标签。

## 隐私与语音处理

Voicely Translate 必须处理语音音频才能提供转录和翻译。

服务器所有者应确保语音频道中的用户明白，在机器人存在期间，它正在转录对话。

只有在有人明确使用 `/join` 后，机器人才会开始翻译会话；可以使用 `/leave` 停止会话。

## 关于 Voicely Translate

Voicely Translate 旨在通过将原始语音和翻译放在对话发生的同一位置，让 Discord 上的多语言语音对话更加轻松。

通话中的每个人无需说同一种语言；参与者可以自然地说话，同时使用语音频道的侧边聊天，以自己理解的语言跟上对话。
