## Benutzerhandbuch

Voicely Translate ist ein Discord-Bot, der Gespräche in Sprachkanälen automatisch transkribiert und in mehrere Sprachen übersetzt. Jede Person wird getrennt verarbeitet – auch bei gleichzeitigem Sprechen – und die Ergebnisse erscheinen im Seitenchat des Sprachkanals.

## Funktionen
* Automatische Transkription und mehrsprachige Übersetzung.
* Mehrere Zielsprachen gleichzeitig.
* Sprachen während einer Sitzung hinzufügen oder entfernen.
* BCP-47-Sprach-Tags ohne feste Whitelist.
* Automatisches Verlassen leerer Sprachkanäle.
* Optional [**Voicely Text**](https://discord.com/application-directory/1290741552158609419) zum Vorlesen.

## Installation und Start
Füge den Bot über [diesen Link](https://discord.com/oauth2/authorize?client_id=1535789654974930964) hinzu, tritt einem normalen Sprachkanal bei und verwende `/join languages:en,ja`. Mehrere Tags werden durch Kommas getrennt. Die Ergebnisse erscheinen im **Seitenchat dieses Sprachkanals**.

`/languages` zeigt häufige Tags wie `en`, `ja`, `es`, `fr`, `de`, `ko`, `zh`, `haw`. Regionale Tags wie `pt-BR` oder `zh-TW` funktionieren ebenfalls. Die Liste ist keine Begrenzung.

## Sitzung ändern
`/add languages:fr,ko` fügt Sprachen hinzu. `/remove languages:en,fr` entfernt sie. `/active` zeigt aktive Sprachen. `/leave` beendet die Sitzung.

## Leerer Kanal
Administratoren können mit `/timeout seconds:60` die Wartezeit einstellen. Standard: **30 Sekunden**.

## Voicely Credits
**100 Voicely Credits = 1,00 USD.** Neue Server erhalten derzeit **50 kostenlose Test-Credits**. Transkription und Übersetzung verbrauchen Credits; mehr Zielsprachen können den Verbrauch erhöhen.

`/balance` zeigt verfügbares, Test- und gekauftes Guthaben. `/usage` zeigt Gesamt-, Transkriptions- und Übersetzungsnutzung sowie Käufe. Credits gehören zum **Discord-Server**.

Mit `/topup` erhalten Administratoren einen eindeutigen Servercode für Ko-fi. **1,00 USD fügt 100 Credits hinzu.** Den Code exakt in die Zahlungsnachricht schreiben und danach `/balance` oder `/join` verwenden.

## Ablauf
1. Audio eines Sprechers empfangen.
2. In der tatsächlich gesprochenen Sprache transkribieren.
3. In die aktivierten Sprachen übersetzen.
4. Original und Übersetzungen im Seitenchat veröffentlichen.

Kurze Pausen markieren das Ende einer Äußerung. Rein nonverbale Geräusche und einzelne Zögerlaute können ignoriert werden.

## Befehle
`/join` starten · `/add` hinzufügen · `/remove` entfernen · `/active` aktive Sprachen · `/languages` Tags · `/leave` beenden · `/balance` Guthaben · `/usage` Nutzung · `/topup` aufladen (Admin) · `/timeout` Wartezeit (Admin).

## Qualität und Datenschutz
Sprich deutlich und vermeide starken Hintergrundlärm. Automatische Systeme können bei Namen, Slang oder mehrdeutigem Audio Fehler machen. Der Bot muss Sprachdaten verarbeiten; Personen im Kanal sollten wissen, dass während seiner Anwesenheit transkribiert wird.
