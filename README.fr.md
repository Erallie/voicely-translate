## Guide utilisateur

Voicely Translate est un bot Discord qui transcrit automatiquement les conversations vocales et les traduit dans plusieurs langues. Chaque personne est traitée séparément, y compris lorsque plusieurs personnes parlent en même temps, et le texte est publié dans le chat latéral du salon vocal.

## Fonctions
* Transcription automatique et traduction multilingue.
* Plusieurs langues actives simultanément.
* Ajout/suppression de langues pendant une session.
* Tags BCP 47 sans liste fermée.
* Départ automatique d'un salon vide.
* Compatibilité avec [**Voicely Text**](https://discord.com/application-directory/1290741552158609419) pour lire les traductions à voix haute.

## Installation et utilisation
Ajoutez le bot avec [ce lien](https://discord.com/oauth2/authorize?client_id=1535789654974930964), rejoignez un salon vocal puis utilisez `/join languages:en,ja`. Séparez plusieurs tags par des virgules. Le bot publie le texte dans **le chat latéral du salon vocal**.

`/languages` affiche des tags courants. Exemples : `en`, `ja`, `es`, `fr`, `de`, `ko`, `zh`, `haw`. Les variantes comme `pt-BR` et `zh-TW` sont acceptées. La liste affichée n'est pas une limite.

## Modifier la session
* `/add languages:fr,ko` — ajouter des langues.
* `/remove languages:en,fr` — retirer des langues.
* `/active` — afficher les langues actives.
* `/leave` — arrêter et quitter.

## Délai
`/timeout seconds:60` règle le délai avant de quitter un salon vide. Valeur par défaut : **30 secondes**. Administrateur uniquement.

## Crédits
**100 crédits Voicely = 1,00 $ USD.** Les nouveaux serveurs reçoivent **50 crédits d'essai gratuits**. Les crédits servent à la transcription et à la traduction ; plus de langues peuvent augmenter l'utilisation.

`/balance` affiche le solde. `/usage` affiche l'utilisation totale, la transcription, la traduction et les achats. Les crédits appartiennent au **serveur Discord**.

Les administrateurs utilisent `/topup` pour obtenir un code unique et acheter des crédits via Ko-fi. Chaque **1,00 $ USD ajoute 100 crédits**. Incluez exactement le code dans le message de paiement, puis utilisez `/balance` ou `/join`.

## Fonctionnement
1. Réception de l'audio de chaque locuteur.
2. Transcription dans la langue réellement parlée.
3. Traduction vers les langues activées.
4. Publication de l'original et des traductions dans le chat latéral.

De courtes pauses déterminent la fin d'une intervention. Les sons non verbaux et hésitations isolées peuvent être ignorés.

## Commandes
`/join` démarrer · `/add` ajouter · `/remove` retirer · `/active` langues actives · `/languages` référence · `/leave` arrêter · `/balance` solde · `/usage` utilisation · `/topup` recharge (admin) · `/timeout` délai (admin).

## Qualité et confidentialité
Parlez clairement et évitez les bruits forts. La transcription automatique peut se tromper sur les noms, l'argot ou l'audio ambigu. Le bot doit traiter l'audio pour fournir le service ; les membres du salon doivent savoir que la conversation est transcrite pendant sa présence. La session commence avec `/join` et s'arrête avec `/leave`.
