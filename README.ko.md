Voicely Translate는 음성 채널에서 이루어지는 대화를 자동으로 받아쓰고 번역하는 Discord 봇입니다.

봇이 음성 채널에서 활성화되어 있으면 각 화자의 음성을 개별적으로 듣고, 말한 내용을 받아쓴 뒤 원문과 번역을 음성 채널의 사이드 채팅에 게시합니다.

여러 번역 언어를 동시에 활성화할 수 있으며, 봇이 이미 번역 중인 동안에도 언어를 추가하거나 제거할 수 있습니다.

## 기능

* Discord 음성 채널의 음성을 자동으로 받아씁니다.
* 대화를 여러 언어로 동시에 번역합니다.
* 받아쓰기와 번역을 음성 채널의 사이드 채팅에 직접 게시합니다.
* 여러 사람이 말하는 상황과 서로 겹쳐 말하는 상황을 지원합니다.
* 세션을 다시 시작하지 않고 번역 언어를 추가하거나 제거할 수 있습니다.
* BCP 47 언어 태그를 사용하므로 고정된 내장 목록 이외의 언어도 요청할 수 있습니다.
* 설정 가능한 시간 제한이 지나면 비어 있는 음성 채널에서 자동으로 나갑니다.
* 선택적으로 [**Voicely Text**](https://discord.com/application-directory/1290741552158609419)와 함께 사용하여 번역된 메시지를 소리 내어 읽을 수 있습니다.

## 서버에 Voicely Translate 추가하기

[이 초대 링크](https://discord.com/oauth2/authorize?client_id=1535789654974930964)를 사용하여 Discord 서버에 Voicely Translate를 추가하세요.

설치하면 명령어를 Discord 슬래시 명령어로 사용할 수 있습니다.

번역을 시작하려면 일반 Discord 음성 채널에 들어간 후 다음을 사용하세요.

`/join`

Voicely Translate가 참가할 음성 채널에 먼저 본인이 들어가 있어야 합니다.

## 번역 세션 시작하기

사용법:

`/join`

`languages` 옵션은 선택 사항입니다. 언어를 지정하면 해당 언어가 번역 세션에 사용됩니다:

`/join languages:<언어 태그>`

여러 언어는 쉼표로 구분하세요.

예:

`/join languages:en,ja`

영어와 일본어가 활성화된 번역 세션을 시작합니다.

필요한 만큼 언어를 활성화할 수 있습니다:

`/join languages:en,ja,es,fr,de,ko`

언어를 지정하지 않고 `/join`을 사용하면 Voicely Translate는 서버의 기본 번역 언어를 사용합니다.

서버에 기본 언어가 설정되어 있지 않으면 봇이 언어를 지정하거나 서버 관리자에게 기본 언어를 설정해 달라고 요청하도록 안내합니다.

연결되면 Voicely Translate는 음성 기록과 번역을 **해당 음성 채널의 사이드 채팅**에 게시합니다.

## 기본 번역 언어

서버 관리자는 `languages` 옵션을 지정하지 않고 `/join`을 실행했을 때 Voicely Translate가 사용할 언어를 설정할 수 있습니다.

사용법:

`/defaultlanguages languages:<언어 태그>`

예:

`/defaultlanguages languages:en,ja`

영어와 일본어를 서버의 기본 번역 언어로 설정합니다.

여러 언어는 쉼표로 구분하세요:

`/defaultlanguages languages:en,ja,es,fr`

이 기본 설정은 Discord 서버에 저장되며 서버 관리자가 변경할 때까지 유지됩니다.

`/join`에서 언어를 직접 지정하면 해당 번역 세션에서는 서버의 기본 언어보다 지정한 언어가 우선합니다. 저장된 기본 설정은 변경되지 않습니다.

이 명령어를 사용하려면 **관리자** 권한이 필요합니다.

## 언어 태그

Voicely Translate는 언어 이름 대신 언어 태그를 사용합니다.

예:

* `en` — 영어
* `ja` — 일본어
* `es` — 스페인어
* `fr` — 프랑스어
* `de` — 독일어
* `ko` — 한국어
* `zh` — 중국어
* `haw` — 하와이어

`pt-BR` 또는 `zh-TW`와 같은 지역별 및 문자 체계별 BCP 47 태그도 사용할 수 있습니다.

다음을 사용하세요.

`/languages`

일반적인 언어 태그의 참고 목록을 볼 수 있습니다.

봇은 **`/languages`에 표시되는 언어로 제한되지 않습니다**. 다른 유효한 BCP 47 언어 태그도 시도할 수 있습니다.

## 번역 중 언어 변경하기

언어를 바꾸기 위해 봇을 나갔다가 다시 참가시킬 필요가 없습니다.

### 언어 추가

다음을 사용하세요.

`/add languages:<언어 태그>`

예:

`/add languages:fr,ko`

현재 번역 세션에 프랑스어와 한국어를 추가합니다.

### 언어 제거

다음을 사용하세요.

`/remove languages:<언어 태그>`

예:

`/remove languages:en,fr`

현재 번역 세션에서 영어와 프랑스어를 제거합니다.

언어를 제거해도 이후 번역에만 영향을 줍니다. 계속 활성화되어 있는 언어로는 번역을 계속할 수 있습니다.

### 활성 언어 보기

다음을 사용하세요.

`/active`

현재 활성화되어 있는 번역 언어를 확인할 수 있습니다.

## 번역 중지하기

다음을 사용하세요.

`/leave`

현재 번역 세션을 중지하고 Voicely Translate가 음성 채널에서 나가도록 합니다.

음성 채널에 아무도 남아 있지 않으면 봇이 자동으로 나갈 수도 있습니다.

## 빈 음성 채널 시간 제한

서버 관리자는 Voicely Translate가 빈 음성 채널에서 자동으로 나가기 전에 얼마나 기다릴지 설정할 수 있습니다.

다음을 사용하세요.

`/timeout seconds:<초>`

예:

`/timeout seconds:60`

음성 채널이 비어 있는 상태가 된 후 봇이 60초 동안 기다리게 합니다.

기본 시간 제한은 **30초**입니다.

이 명령어에는 **관리자(Administrator)** 권한이 필요합니다.

## Voicely Credits

Voicely Translate는 음성 대화를 처리하는 데 필요한 받아쓰기 및 번역 서비스 비용을 지불하기 위해 크레딧 시스템을 사용합니다.

**100 Voicely Credits = $1.00 USD.**

새 서버에는 현재 **50 무료 체험 크레딧**이 제공됩니다. 이는 일반적인 음성 메시지 약 **500개**를 처리할 수 있는 양이지만, 실제 사용량은 달라질 수 있습니다.

음성이 받아쓰기되고 번역될 때 크레딧이 사용됩니다. 사용량은 사람들이 얼마나 많이 말하는지와 몇 개의 번역이 요청되는지에 따라 달라질 수 있습니다.

번역 언어를 더 많이 활성화하면 각 받아쓰기를 요청된 언어로 번역해야 하므로 사용량이 증가할 수 있습니다.

### 잔액 확인

다음을 사용하세요.

`/balance`

다음을 확인할 수 있습니다.

* 사용 가능한 크레딧
* 남은 무료 체험 크레딧
* 구매한 크레딧

### 사용량 확인

다음을 사용하세요.

`/usage`

다음을 포함한 서버의 누적 사용량을 확인할 수 있습니다.

* 총 API 사용량
* 받아쓰기 사용량
* 번역 사용량
* 총 구매 크레딧

크레딧 잔액과 사용량은 개별 Discord 사용자가 아니라 **Discord 서버**에 속합니다.

## 크레딧 추가하기

서버 관리자는 다음을 사용할 수 있습니다.

`/topup`

Voicely Translate는 서버 전용 고유 충전 코드와 Ko-fi를 통해 추가 크레딧을 구매하는 방법을 제공합니다.

결제할 때 제공된 충전 코드를 Ko-fi 결제 메시지에 포함하세요.

**$1.00 USD마다 100 Voicely Credits가 추가됩니다**.

결제한 후 다음을 사용하세요.

`/balance`

또는 `/join`으로 봇을 시작하기만 해도 됩니다.

Voicely Translate가 새로 구매한 크레딧을 자동으로 확인합니다.

`/topup` 명령어에는 **관리자(Administrator)** 권한이 필요합니다.

## 번역 작동 방식

누군가 음성 채널에서 말하면 Voicely Translate는 그 사람의 음성을 독립적으로 처리합니다.

기본 과정은 다음과 같습니다.

1. Voicely Translate가 화자의 음성 오디오를 받습니다.
2. 오디오를 실제로 말하고 있는 언어로 받아씁니다.
3. 받아쓴 내용을 현재 활성화된 언어로 번역합니다.
4. 원문 받아쓰기와 번역을 음성 채널의 사이드 채팅에 게시합니다.

화자를 독립적으로 처리하므로 여러 사람이 동시에 또는 거의 동시에 말하는 대화를 처리할 수 있도록 설계되어 있습니다.

짧은 침묵을 사용하여 발화가 끝났는지 판단한 후 받아쓰기로 전송합니다.

비언어적 소리와 단독으로 나온 망설임 소리는 메시지로 게시되지 않고 무시될 수 있습니다.

## 예시

세 사람이 음성 채널에 있고 영어, 일본어, 스페인어가 활성화되어 있다고 가정해 보겠습니다.

누군가 다음과 같이 말합니다.

> Are we ready to go?

Voicely Translate는 원문 받아쓰기와 함께 다음과 같은 번역을 게시할 수 있습니다.

**원문 — 영어**  
Are we ready to go?

**일본어**  
もう行く準備はできた？

**스페인어**  
¿Estamos listos para irnos?

정확한 형식과 번역은 달라질 수 있습니다.

## Voicely Text 사용하기

Voicely Translate는 번역을 텍스트로 표시하도록 설계되었습니다.

번역된 메시지를 **음성 채널에서 소리 내어 읽고 싶다면**, Voicely Translate를 [**Voicely Text**](https://discord.com/application-directory/1290741552158609419)와 함께 사용할 수 있습니다.

Voicely Text가 설치되어 있지 않은 서버에 Voicely Translate가 참가하면 추가할 수 있는 링크를 제공할 수 있습니다.

## 더 나은 결과를 위한 팁

최상의 받아쓰기 및 번역 품질을 위해:

* 명확하고 정상적인 음량으로 말하세요.
* 지나치게 큰 배경 음악이나 소음을 피하세요.
* 대화에 가장 적합한 언어 태그를 사용하세요.
* 자동 받아쓰기와 번역은 특히 이름, 속어, 매우 짧은 발화, 심한 배경 소음 또는 모호한 음성에서 실수할 수 있다는 점을 기억하세요.
* 지역 차이가 중요한 경우 지역 언어 태그를 사용하세요.

## 개인정보 보호 및 음성 처리

Voicely Translate는 받아쓰기와 번역을 제공하기 위해 음성 오디오를 처리해야 합니다.

서버 소유자는 음성 채널을 사용하는 사람들이 봇이 있는 동안 대화가 받아쓰기되고 있다는 사실을 이해하도록 해야 합니다.

봇은 누군가 명시적으로 `/join`을 사용한 후에만 번역 세션을 시작하며, `/leave`를 사용하여 세션을 중지할 수 있습니다.

## Voicely Translate 소개

Voicely Translate는 원래 음성과 번역을 대화가 이루어지는 같은 장소에 함께 표시하여 다국어 Discord 음성 대화를 더 쉽게 만들도록 설계되었습니다.

통화에 참여한 모든 사람이 같은 언어를 말할 필요 없이, 참가자는 자연스럽게 말하면서 음성 채널의 사이드 채팅을 통해 자신이 이해하는 언어로 대화를 따라갈 수 있습니다.
