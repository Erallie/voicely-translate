Voicely Translate — это Discord-бот, который автоматически расшифровывает и переводит разговоры в голосовых каналах.

Когда бот активен в голосовом канале, он отдельно слушает каждого говорящего, расшифровывает его речь и публикует исходную расшифровку вместе с переводами в боковом чате голосового канала.

Одновременно можно включить несколько языков перевода, а добавлять или удалять языки можно даже во время работы бота.

## Возможности

* Автоматически расшифровывает речь из голосовых каналов Discord.
* Одновременно переводит разговоры на несколько языков.
* Публикует расшифровки и переводы непосредственно в боковом чате голосового канала.
* Поддерживает нескольких говорящих, в том числе когда их речь накладывается друг на друга.
* Позволяет добавлять и удалять языки перевода без перезапуска сеанса.
* Использует языковые теги BCP 47, поэтому можно запрашивать языки за пределами фиксированного встроенного списка.
* Автоматически выходит из пустого голосового канала после настраиваемого периода ожидания.
* При желании может использоваться вместе с [**Voicely Text**](https://discord.com/application-directory/1290741552158609419), чтобы озвучивать переведённые сообщения.

## Добавление Voicely Translate на сервер

Добавьте Voicely Translate на свой сервер Discord с помощью [этой ссылки-приглашения](https://discord.com/oauth2/authorize?client_id=1535789654974930964).

После установки команды будут доступны как slash-команды Discord.

Чтобы начать перевод, войдите в обычный голосовой канал Discord и используйте:

`/join`

Вы уже должны находиться в голосовом канале, к которому должен присоединиться Voicely Translate.

## Запуск сеанса перевода

Используйте:

`/join`

Параметр `languages` является необязательным. Если вы укажете языки, они будут использоваться для этого сеанса перевода:

`/join languages:<языковые теги>`

Разделяйте несколько языков запятыми.

Например:

`/join languages:en,ja`

Это запустит сеанс перевода с английским и японским языками.

Вы можете включить столько языков, сколько необходимо:

`/join languages:en,ja,es,fr,de,ko`

Если вы используете `/join`, не указывая языки, Voicely Translate будет использовать языки перевода по умолчанию, установленные для сервера.

Если для сервера не настроены языки по умолчанию, бот попросит вас указать языки или обратиться к администратору сервера, чтобы он настроил языки по умолчанию.

После подключения Voicely Translate будет публиковать транскрипции и переводы в **боковом чате соответствующего голосового канала**.

## Языки перевода по умолчанию

Администраторы сервера могут установить языки, которые Voicely Translate будет использовать, когда кто-либо запускает `/join`, не указывая параметр `languages`.

Используйте:

`/defaultlanguages languages:<языковые теги>`

Например:

`/defaultlanguages languages:en,ja`

устанавливает английский и японский в качестве языков перевода по умолчанию для сервера.

Разделяйте несколько языков запятыми:

`/defaultlanguages languages:en,ja,es,fr`

Эти настройки сохраняются для Discord-сервера и действуют до тех пор, пока администратор сервера их не изменит.

Если языки указаны непосредственно в `/join`, они заменяют языки сервера по умолчанию только для этого сеанса перевода. Сохранённые настройки по умолчанию при этом не изменяются.

Для использования этой команды требуется разрешение **Администратор**.

## Языковые теги

Voicely Translate использует языковые теги вместо названий языков.

Например:

* `en` — Английский
* `ja` — Японский
* `es` — Испанский
* `fr` — Французский
* `de` — Немецкий
* `ko` — Корейский
* `zh` — Китайский
* `haw` — Гавайский

Также можно использовать региональные и зависящие от письменности теги BCP 47, например `pt-BR` или `zh-TW`.

Используйте:

`/languages`

чтобы просмотреть справочный список распространённых языковых тегов.

Бот **не ограничен языками, показанными в `/languages`**. Можно попробовать и другие действительные языковые теги BCP 47.

## Изменение языков во время перевода

Не нужно заставлять бота выходить и входить снова только ради смены языков.

### Добавление языков

Используйте:

`/add languages:<языковые теги>`

Например:

`/add languages:fr,ko`

добавляет французский и корейский языки в текущий сеанс перевода.

### Удаление языков

Используйте:

`/remove languages:<языковые теги>`

Например:

`/remove languages:en,fr`

удаляет английский и французский языки из текущего сеанса перевода.

Удаление языка влияет только на будущие переводы. Бот продолжит переводить на все языки, которые остаются включёнными.

### Просмотр активных языков

Используйте:

`/active`

чтобы увидеть, какие языки перевода сейчас включены.

## Остановка перевода

Используйте:

`/leave`

чтобы остановить текущий сеанс перевода и заставить Voicely Translate выйти из голосового канала.

Бот также может автоматически выйти, когда в голосовом канале никого не останется.

## Тайм-аут пустого голосового канала

Администраторы сервера могут настроить, сколько времени Voicely Translate будет ждать в пустом голосовом канале перед автоматическим выходом.

Используйте:

`/timeout seconds:<секунды>`

Например:

`/timeout seconds:60`

заставляет бота ждать 60 секунд после того, как голосовой канал опустеет.

Тайм-аут по умолчанию составляет **30 секунд**.

Для этой команды требуется разрешение **Администратор (Administrator)**.

## Voicely Credits

Voicely Translate использует систему кредитов для оплаты сервисов расшифровки и перевода, необходимых для обработки голосовых разговоров.

**100 Voicely Credits = $1.00 USD.**

Новые серверы в настоящее время получают **50 бесплатных пробных кредитов**.

Кредиты расходуются по мере расшифровки и перевода речи. Расход зависит от того, сколько говорят участники и сколько переводов запрашивается.

Включение дополнительных языков перевода может увеличить расход, поскольку каждую расшифровку необходимо перевести на запрошенные языки.

### Проверка баланса

Используйте:

`/balance`

чтобы увидеть:

* Доступные кредиты
* Оставшиеся бесплатные пробные кредиты
* Купленные кредиты

### Проверка использования

Используйте:

`/usage`

чтобы увидеть накопленное использование сервера, включая:

* Общее использование API
* Использование расшифровки
* Использование перевода
* Всего куплено кредитов

Баланс кредитов и статистика использования относятся к **серверу Discord**, а не к отдельному пользователю Discord.

## Добавление кредитов

Администраторы сервера могут использовать:

`/topup`

Voicely Translate предоставит уникальный код пополнения для сервера и инструкции по покупке дополнительных кредитов через Ko-fi.

При оплате укажите предоставленный код пополнения в сообщении платежа Ko-fi.

Каждый **$1.00 USD добавляет 100 Voicely Credits**.

После оплаты используйте:

`/balance`

или просто запустите бота с помощью `/join`.

Voicely Translate автоматически проверит наличие недавно приобретённых кредитов.

Для команды `/topup` требуется разрешение **Администратор (Administrator)**.

## Как работает перевод

Когда кто-то говорит в голосовом канале, Voicely Translate обрабатывает речь этого человека независимо.

Основной процесс:

1. Voicely Translate получает голосовой звук говорящего.
2. Аудио расшифровывается на языке, на котором действительно говорят.
3. Расшифровка переводится на языки, включённые в данный момент.
4. Исходная расшифровка и переводы публикуются в боковом чате голосового канала.

Поскольку каждый говорящий обрабатывается отдельно, бот рассчитан на разговоры, в которых несколько человек могут говорить одновременно или почти одновременно.

Короткие паузы используются для определения окончания реплики перед отправкой на расшифровку.

Невербальные звуки и отдельные звуки колебания могут игнорироваться вместо публикации в виде сообщений.

## Пример

Представьте, что в голосовом канале находятся три человека и включены английский, японский и испанский языки.

Кто-то говорит:

> Are we ready to go?

Voicely Translate может опубликовать исходную расшифровку вместе с такими переводами:

**Оригинал — английский**  
Are we ready to go?

**Японский**  
もう行く準備はできた？

**Испанский**  
¿Estamos listos para irnos?

Точное форматирование и переводы могут отличаться.

## Использование Voicely Text

Voicely Translate предназначен для отображения переводов в виде текста.

Если вы также хотите, чтобы переведённые сообщения **зачитывались вслух в голосовом канале**, можно использовать Voicely Translate вместе с [**Voicely Text**](https://discord.com/application-directory/1290741552158609419).

Когда Voicely Translate присоединяется к серверу, где Voicely Text не установлен, он может предоставить ссылку для его добавления.

## Советы для лучших результатов

Для наилучшего качества расшифровки и перевода:

* Говорите чётко и с нормальной громкостью.
* Избегайте очень громкой фоновой музыки или шума.
* Используйте языковые теги, наиболее подходящие для разговора.
* Помните, что автоматическая расшифровка и перевод могут допускать ошибки, особенно в именах, сленге, очень коротких репликах, при сильном фоновом шуме или неоднозначной речи.
* Используйте региональные языковые теги, когда различие важно.

## Конфиденциальность и обработка голоса

Voicely Translate должен обрабатывать голосовой звук для предоставления расшифровки и перевода.

Владельцы серверов должны убедиться, что пользователи голосового канала понимают, что бот расшифровывает разговор, пока находится в канале.

Бот начинает сеанс перевода только после явного использования команды `/join`, а `/leave` можно использовать для остановки сеанса.

## О Voicely Translate

Voicely Translate создан для упрощения многоязычных голосовых разговоров в Discord, размещая исходную речь и переводы вместе там же, где происходит разговор.

Вместо того чтобы требовать от всех участников звонка говорить на одном языке, они могут говорить естественно и использовать боковой чат голосового канала, чтобы следить за разговором на понятных им языках.
